## 摘要

以无人船 Simulink 建模为载体，自行设计了一个按规则约束流程的专用智能体，并与不做任何预设的通用智能体放在同一组递进任务上对照。专用智能体把流程拆成“设计图—人审核—编码”两段，在写代码之前设一道人工确认门。三个递进任务的完成度没有差别，差异在于判断是否可见：通用智能体累积了十项未经确认的静默决策，专用智能体则把这些判断逐项交回给人。实验验证了这套设计的有效性：判断不再被静默完成，而是停在设计图这道确认门上，由人来决定；三项任务均能按该流程有效完成模型设计与仿真验证。
