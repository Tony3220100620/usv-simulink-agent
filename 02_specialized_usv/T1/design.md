# 正弦信号增益放大与示波器显示模型 —— 设计方案（第一段：仅设计，不写代码）

## 1. 需求与目标

用 MATLAB 脚本以编程方式创建一个 Simulink 模型，实现"正弦信号 → 增益放大 → 示波器显示"，并同时保留"正弦信号 → 示波器"的原始信号支路，便于在同一示波器内对比放大前后的波形。脚本需完成建模、连线、布局、仿真参数设置、保存与自动打开模型。

配套交付物（第二段实现）：
- `.m` 建模脚本（可在 MATLAB 中直接运行）
- 仿真实验报告 `.docx`
- 工作日志 `.md`

## 2. 模块选型合法性核对

本次全部模块均来自 Simulink 官方自带公共库（Sources / Math Operations / Sinks），未使用 usv_lib 下任何模块，因此按规则无需核对 `modules.md` 模块清单，不存在模块缺失风险。

## 3. 模块设计表

| 字段 | 模块一 | 模块二 | 模块三 |
|---|---|---|---|
| 模块名称 | 正弦信号源 | 增益放大器 | 示波器 |
| 模块ID | M1 | M2 | M3 |
| 模块类型 | Sine Wave（正弦波发生器） | Gain（增益/比例放大器） | Scope（示波器） |
| 来源地址 | Simulink 官方库：`simulink/Sources/Sine Wave` | Simulink 官方库：`simulink/Math Operations/Gain` | Simulink 官方库：`simulink/Sinks/Scope` |
| 可配置参数 | 正弦类型 SineType = Time based；幅值 Amplitude = `A_SINE`（默认 1）；偏置 Bias = 0；角频率 Frequency = `2*pi*F_SINE`（默认 2π rad/s，即 1 Hz）；初相位 Phase = 0；采样时间 SampleTime = 0（连续） | 增益 Gain = `K_GAIN`（默认 10）；乘法方式 Multiplication = Element-wise(K.*u)；采样时间 SampleTime = -1（继承） | 输入端口数 NumInputPorts = 2；分屏布局 LayoutDimensionsString = `[2 1]`（上下两幅，独立纵轴自动缩放）；时间跨度 TimeSpan = auto；仿真开始时自动打开 OpenAtSimulationStart = on；显示图例 ShowLegend = on |
| 输入端口说明 | 无输入端口 | 1 个输入端口（端口 1），接收待放大的原始正弦信号，数据类型 double 标量 | 2 个输入端口：端口 1 显示原始正弦信号；端口 2 显示增益放大后的正弦信号 |
| 输出端口说明 | 1 个输出端口（端口 1），输出幅值 `A_SINE`、频率 `F_SINE` 的连续正弦信号 | 1 个输出端口（端口 1），输出 `K_GAIN` 倍放大后的正弦信号 | 无输出端口（纯显示） |
| 端口连线关系 | 输出端口 1 分出两支：→ M2 输入端口 1；→ M3 输入端口 1 | 输入端口 1 ← M1 输出端口 1；输出端口 1 → M3 输入端口 2 | 输入端口 1 ← M1 输出端口 1（原始信号）；输入端口 2 ← M2 输出端口 1（放大信号） |

连线清单：

| 连线ID | 起点 | 终点 | 说明 |
|---|---|---|---|
| L1 | M1/1（Sine Wave 输出） | M2/1（Gain 输入） | 主通路：正弦信号送入增益器 |
| L2 | M2/1（Gain 输出） | M3/2（Scope 第 2 输入） | 放大后信号送入示波器下方分屏 |
| L3 | M1/1（Sine Wave 输出，与 L1 同源分支） | M3/1（Scope 第 1 输入） | 原始信号送入示波器上方分屏，用于对比 |

## 4. 布局设计（坐标单位：像素，格式 [左 上 右 下]）

| 模块 | 位置 | 设计意图 |
|---|---|---|
| M1 正弦信号源 | `[80 78 130 118]` | 位于最左侧，输出口纵坐标 y=98，正对示波器第 1 输入口 |
| M2 增益放大器 | `[260 164 310 204]` | 位于中部偏下，输出口纵坐标 y=184，正对示波器第 2 输入口 |
| M3 示波器 | `[480 56 530 226]` | 位于最右侧，纵向拉高以容纳上下两个分屏；两个输入口分别位于 y=98、y=184 |

模块横向间距 130 px、无重叠；L3 为水平直线（y=98）直接进入示波器上端口，L1 由 M1 输出向下折向 M2 输入，L2 为水平直线（y=184）进入示波器下端口，三条连线互不交叉遮挡。

## 5. 模型级参数设计

| 参数项 | 取值 | 说明 |
|---|---|---|
| 模型名称 | `usv_sine_gain_scope.slx` | 可改为自定义名称 |
| 保存路径 | 脚本所在目录 | 用 `fileparts(mfilename('fullpath'))` 获取，保证换机可用 |
| 求解器 Solver | ode45（变步长），MaxStep = 1/(100·F_SINE) = 0.01 s | Simulink 默认求解器，兼容性最好；限制最大步长使波形平滑、峰值采样准确 |
| 起始时间 StartTime | 0 s | — |
| 停止时间 StopTime | `T_STOP`，默认 5 s | 1 Hz 正弦下含 5 个完整周期，可完整观测放大波形 |
| 信号记录 | 开启示波器自身的数据记录（Scope 的 DataLogging 属性，变量名 `ScopeData`，Dataset 格式） | 仅用于报告绘图取数，不增加任何模块；R2024b 中信号线不具备 DataLogging 属性，故改用示波器记录 |

## 6. 脚本结构设计（第二段实现，对应 .m 文件）

1. 参数配置区（集中置顶，标注"可自定义修改"）：`MODEL_NAME`、`A_SINE`、`F_SINE`、`K_GAIN`、`T_STOP`。
2. 模型创建区：`new_system` → `open_system` → 设定求解器与停止时间。
3. 模块添加区：三次 `add_block`，名称 `Sine Wave`、`Gain`、`Scope`。
4. 参数配置区：三次 `set_param`。
5. 连线区：按 L1 → L2 → L3 顺序 `add_line`。
6. 布局区：三次 `set_param(...,'Position',...)`。
7. 保存与打开区：`save_system` → `open_system`（脚本末尾自动弹出模型窗口）。
8. 可选仿真区：`sim` 返回 `logsout`，供报告绘图使用（默认注释或置于脚本末尾）。
9. 每段前添加中文注释，参数修改处单独标注。

## 7. 兼容性说明

仅使用 `new_system / open_system / add_block / add_line / set_param / save_system / sim` 等长期稳定的基础 API；Scope 的 `NumInputPorts`、`Layout` 属性自 R2014b 起可用。本机环境为 MATLAB R2024b，脚本按 R2016b 及以上通用写法编写。

## 8. 用户确认结论（已定稿）

1. Simulink 模型中保持"单个示波器 + 上下两分屏（2 个输入端口）"方案；但在仿真数据处理与实验报告撰写阶段，必须把原始正弦曲线与放大后正弦曲线绘制在同一幅图中，便于直接比较幅值差异与相位一致性。
2. 默认参数按 A=1、f=1 Hz、K=10、T=5 s 设定，确认无误。
3. `.m` 脚本、`.slx` 模型、`.docx` 报告、`.md` 日志统一放在 `R3` 目录；报告插图与仿真数据作为支撑文件放在 `R3/figures` 子目录。
