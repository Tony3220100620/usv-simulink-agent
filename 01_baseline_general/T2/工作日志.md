# 工作日志：无人船三自由度 Fossen 模型开环仿真

日期：2026-11-19
任务：在 Simulink 中用 MATLAB 脚本搭建 3 自由度 Fossen 无人船开环模型，完成三种单输入工况仿真并生成报告。

## 一、任务目标

- 输入：纵向力 X、横向力 Y、艏摇力矩 N
- 输出：位置 (x, y)、姿态 ψ、速度 (u, v, r)
- 工况：单独施加 X = 10 N、Y = 5 N、N = 5 N·m，各仿真 12 s
- 交付：.m 脚本、.slx 模型、.docx 报告、.md 工作日志

## 二、运行环境

| 项目 | 内容 |
| --- | --- |
| MATLAB | R2024b（含 Simulink、Stateflow） |
| 求解器 | ode4 定步长，步长 0.01 s，仿真时长 12 s |
| 建模方式 | 脚本调用 new_system / add_block / add_line / set_param 自动建模型 |
| 报告生成 | Python 3 + python-docx，经 Word 转 PDF 检查排版 |

## 三、主要操作步骤

1. 确定模型结构：三自由度 Fossen 模型，M、D 取对角阵，C(ν) 保留 v·r、u·r 耦合项；
   选定船体参数 m11 = 40 kg、m22 = 50 kg、m33 = 12 kg·m²、d11 = 8、d22 = 25、d33 = 25（N·s/m 或 N·m·s/rad）。
2. 参数校核：按稳态增益与时间常数预估三种工况的可观测量（u 稳态 1.25 m/s、v 稳态 0.2 m/s、
   r 稳态 0.2 rad/s、时间常数 5 s / 2 s / 0.48 s），确认 12 s 内三种运动均清晰可见。
3. 编写建模脚本 usv_3dof_openloop_main.m：建模型、放模块、写入 MATLAB Function 代码、连线、保存 .slx。
4. 处理脚本化建模的两个技术点：
   - MATLAB Function 模块内部代码通过 Stateflow 根对象定位 EMChart 后写入 Script 属性；
   - 参数以数值形式写入模块代码，保证保存后的 .slx 脱离脚本也能独立运行。
5. 依次运行三种工况（通过 set_param 改写 Constant 模块的 Value），用 To Workspace 记录 6 个状态量。
6. 结果校验：与一阶惯性环节解析解逐项对比，六个关键量在四位小数上完全一致。
7. 输出三张 2×2 响应曲线图（轨迹、线速度、艏向角、艏摇角速度）及 CSV 数据，并导出模型框图。
8. 撰写并生成 .docx 报告：摘要、任务需求、数学模型（含公式与参数表）、模型实现、结果分析、结论、文件清单。
9. 将报告转 PDF 逐页检查排版（公式编号右对齐、图表位置、分页空白、字体），修正三处分页/字号问题后定稿。
10. 整理交付文件，编写本工作日志。

## 四、仿真结果摘要

| 工况 | 主要响应（t = 12 s） | 说明 |
| --- | --- | --- |
| X = 10 N | u = 1.1366 m/s，x = 9.317 m | 沿 x 轴前进，v、r、ψ 恒为零 |
| Y = 5 N | v = 0.1995 m/s，y = 2.001 m | 纯侧移，u、r、ψ 恒为零 |
| N = 5 N·m | r = 11.459 °/s，ψ = 132.0° | 原地回转，x、y 恒为零 |

三种工况的数值解与解析解相对偏差均小于 0.01%，模型实现正确。
